====================================================
  3 STAR LAYER FARM - Management System
  HOW TO USE - READ THIS FIRST
====================================================

STEP 1: INSTALL PYTHON (one time only)
---------------------------------------
- Go to https://python.org/downloads
- Download Python 3.11 or newer
- During install, CHECK the box that says "Add Python to PATH"
- Click Install Now

STEP 2: START THE APP
----------------------
- Double-click the file: START_FARM_APP.bat
- A black window will open (do not close it)
- Your browser will open automatically
- The app is ready to use!

STEP 3: STOP THE APP
----------------------
- Just close the black window when done

====================================================
  WHERE IS MY DATA SAVED?
====================================================

Your data is saved in the file: farm_data.db
This file is in the same folder as this app.
As long as this file exists, ALL your data is safe.

====================================================
  HOW TO BACKUP YOUR DATA
====================================================

METHOD 1 (Easy): 
- Click the "Backup Data" button inside the app
- It will download a backup file to your Downloads folder
- Copy that file to a USB drive or WhatsApp to yourself

METHOD 2 (Manual):
- Copy the file "farm_data.db" to a USB drive or another folder
- To restore: paste it back in this same folder

====================================================
  HOW TO RESTORE DATA
====================================================

If data is lost or deleted:
1. Find your backup file (e.g. farm_backup_20260601.db)
2. Rename it to: farm_data.db
3. Paste it in this folder (replace the old one)
4. Start the app - all your data is back!
